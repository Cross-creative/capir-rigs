Catálogo de Rigs

Rigs e modelos prontos para baixar e usar no Roblox Studio. Escolha um item abaixo para baixar o arquivo.

Configuração necessária

Edite as constantes GITHUB_OWNER e GITHUB_REPO no início do <script> com os dados do seu repositório antes de publicar este site. Até lá, o catálogo mostra apenas itens de exemplo.

Entrar como criador

O token precisa de permissão de leitura e escrita em "Contents" apenas neste repositório.

Não foi possível validar. Confira o token e as constantes GITHUB_OWNER/GITHUB_REPO no código.

Adicionar novo rig

O catálogo fica salvo como rigs.json no seu repositório do GitHub — qualquer pessoa que abrir este site lê esse arquivo direto do GitHub. Só quem tem o token de acesso consegue adicionar ou remover itens. Os arquivos dos rigs em si ficam hospedados fora daqui (GitHub Releases, Drive, etc.), este site guarda só o nome, a descrição e o link de cada um.
